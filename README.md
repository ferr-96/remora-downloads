# Remora for Mac

Use your Mac from your iPhone or iPad. Remora Host runs on the Mac you want to control; Remora on your phone or tablet connects to it.

## Requirements

- A Mac with Apple silicon (M1 or later), running macOS 14 or later.
- Administrator access to install the companion software and approve macOS permissions.
- Remora for iPhone/iPad requires iOS/iPadOS 17 or later.
- Internet access on both devices for an internet connection. A new Host needs relay enrollment; downloading the installer alone does not enroll it.

## Download

Version1.1.32 is an App Store review candidate. The iPhone/iPad app is not yet publicly available on the App Store. Internet setup needs an assigned enrollment code; contact support before installing.

Use the installer and matching uninstaller attached to a published release in this repository. Check their SHA-256 values against the release checksums. This repository contains distribution materials; it does not contain Remora's application source.

Read [Setup](SETUP.md) before installing and [Removal](UNINSTALL.md) when uninstalling. [Third-party notices](THIRD-PARTY-NOTICES.md) accompany the software.
